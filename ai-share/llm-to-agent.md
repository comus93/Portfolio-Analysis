## Context

Korean market v1 구현은 완료되었고, 사용자가 로컬 UAT를 시작하기 전에 국내 종목 지정 UX를 보완한다.

기존 6자리 종목코드 직접 입력 방식은 유지하되, 웹 UI에서 유사 종목이 임의로 확정되는 위험을 막아야 한다.

## Message

국내 종목 지정 UI를 다음 요구사항으로 보완해줘.

1. 사용자는 국내 상장 주식/ETF를 **종목코드 또는 종목명으로 검색**할 수 있어야 한다.
2. 검색어 자체를 종목으로 바로 확정하지 말고, **검색 결과 목록을 먼저 표시**한다.
3. 검색 결과에는 최소한 다음 정보를 표시한다.
   - 6자리 종목코드
   - 종목명
   - 주식/ETF 구분이 안정적으로 제공 가능하면 함께 표시
4. 사용자가 검색 결과 중 하나를 **명시적으로 선택해야만** 포트폴리오 종목으로 확정한다.
5. 부분일치/LIKE/유사 검색 결과의 첫 번째 항목을 자동 선택하거나, 유사 종목을 임의 추정해서는 안 된다.
6. 정확한 6자리 종목코드를 입력한 경우에도 해당 코드의 종목명을 검색 결과에서 확인한 뒤 선택할 수 있게 한다.
7. 선택된 종목은 화면에서 **종목코드 + 종목명**을 함께 식별할 수 있어야 한다.
8. 기존 포트폴리오의 비중 입력 흐름과 종목 추가/삭제가 자연스럽게 동작해야 한다.
9. Benchmark 입력에도 동일한 **검색 → 결과 확인 → 명시적 선택** 원칙을 적용한다.
10. 기존 6자리 종목코드 직접 입력/빠른 입력 기능이 있다면 fallback으로 유지하여 검색 기능 장애가 전체 분석 기능 장애로 이어지지 않게 한다.

이번 범위에서는 다음 기능은 추가하지 않는다.

- 포트폴리오 저장
- 즐겨찾기
- 최근 사용 종목
- 테마/섹터/운용사 필터
- 고급 fuzzy search
- 현재가/종목 상세정보
- ETF 구성종목 조회

검색/종목 메타데이터 기능은 가격 데이터 로딩 및 기존 분석 로직과 가능한 한 분리하고, 불필요한 구조 변경은 하지 말 것.
